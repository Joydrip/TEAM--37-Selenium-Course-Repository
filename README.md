## 📚 Assignment Details

### 🔹 Installation & Environment Setup
Demonstration of configuring the Python environment, installing the `selenium` package via `pip`, and initializing the Chrome WebDriver instance.

### 🔹 Assignment 1 — Web Element Identification
Locating single web elements across standard HTML structures using fundamental Selenium locator strategies:
* `By.ID` & `By.NAME` for form fields
* `By.CLASS_NAME` for stylized targets
* `By.TAG_NAME` for document tags
* `By.LINK_TEXT` for hyperlink anchors

### 🔹 Assignment 2 — Multiple Element Identification
Extracting collections of similar elements using `find_elements()` to retrieve a list of `WebElement` instances, iterating through the collection, and extracting attributes (`text`, `href`).

### 🔹 Assignment 3 — CSS Selector Challenge
Targeting dynamic elements with variable attributes using CSS attribute wildcard operators:
* `^=` : Prefix match (attribute begins with specified text)
* `$=` : Suffix match (attribute ends with specified text)
* `*=` : Substring match (attribute contains specified text)

### 🔹 Assignment 4 — Child Nodes Using CSS
Traversing parent-child and nested DOM trees using CSS combinators:
* Direct child operator (`>`) to match immediate children
* Descendant combinator (` ` space) to reach deeply nested children inside parent containers
